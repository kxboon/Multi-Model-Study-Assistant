# PyTorch (CPU-only build - avoids the ~2 GB CUDA download)
#
# IMPORTANT: `pip install -r requirements.txt` ALONE DOES NOT PRODUCE A WORKING
# ENVIRONMENT. torch cannot be listed as a requirement in this file: the "+cpu"
# builds live only on the PyTorch wheel index, and a plain `torch==` line would
# resolve against PyPI and pull the CUDA build. Install it FIRST, with these
# exact versions:
#
#   pip install torch==2.11.0+cpu torchvision==0.26.0+cpu torchaudio==2.11.0+cpu --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements.txt
#
# In that order. openai-whisper and sentence-transformers both depend on torch,
# so installing this file first would drag in the CUDA build as a transitive
# dependency and defeat the point.
#
# These versions are PINNED FOR REPRODUCIBILITY, not merely as minimums. The
# project reports latency and accuracy measurements - transcription, captioning,
# embedding, retrieval and sentiment timings, and the model outputs behind them
# - all taken under this exact stack. Installing a different torch may change
# both the numbers and the results they describe, so the reported figures would
# no longer correspond to the environment being run.
#
# Recorded here for reference only - do NOT uncomment, they would resolve
# against PyPI and defeat the purpose:
# torch==2.11.0+cpu
# torchvision==0.26.0+cpu
# torchaudio==2.11.0+cpu
